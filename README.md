
# 全国子育てママ応援ナビ

## 目的
全国の子育て家庭が、自治体の子育て支援や生活環境を調べられるAndroidアプリ。

## 決定事項
- 初回公開は無料・広告あり
- 全国47都道府県・市区町村に対応
- 基本的な子育て支援、ひとり親支援、緊急相談窓口は無料
- 将来的に広告非表示などのアプリ内課金を検討
- 背景画像は後日制作し、機能を優先

## キャッチコピー
引っ越ししても大丈夫！あなたと家族に合う、安心して子育てできる地域が見つかる。

## 画面
1. ホーム（都道府県・市区町村選択）
2. 自治体詳細（保育・学童・医療・助成金・ひとり親支援・相談窓口）
3. 地域比較（2地域）
4. お気に入り
5. 出典・更新日・免責

## 情報項目
自治体コード、都道府県、市区町村、制度分類、制度名、対象条件、概要、公式URL、確認日、更新日、注意事項。

## 開発方針
- GitHub中心で開発
- 最初はローカルデータで検索画面を作る
- 開発中はテスト広告のみ
- 位置情報の許可なしでも自治体を選べる
- 実際の制度条件は自治体公式ページで確認する
